# Module 3: High-Energy Particle Phenomenology Spectrum

Advanced production-ready Python simulation code, covariant electroweak coupling solvers, and thermodynamic boundaries for comoving Zepto-scale quantum regularization.

## Repository Contents
* `advanced_spectral_resonances.py`: Analytical Bessel resonance calculator mapping higher-order quadrupole (l=2) and octupole (l=3) modes to high-energy accelerator frontiers (FCC-hh).
* `higgs_mass_coupling.py`: Covariant Yukawa mass generation mechanics evaluating stable lighter resonances within the 18 to 27 GeV window.
* `unruh_thermal_spectrum.py`: Relativistic thermodynamics calculator computing the finite Unruh radiation temperature and thermal energy peaks at the comoving cosmic bounce core.

## Requirements & Execution
```bash
pip install numpy
python advanced_spectral_resonances.py
python higgs_mass_coupling.py
python unruh_thermal_spectrum.py
```
